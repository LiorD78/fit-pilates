## STRATEGIE

Tohle není tlačený PR text typu *„nový web pilates studia"*. Tohle je **human-interest story** s konkrétními postavami a hodnotovým střetem (longevity vs fitness, premium vs masová branže). Důvod, proč by si to redaktoři měli pustit:

1. **Konkrétní lidé, konkrétní příběh.** CEO 3 firem, 20 let u jednoho trenéra, before/after fotky. Není to abstraktní fitness téma.
2. **Trend Long-form/longevity.** ICP target (Forbes, E15, Hospodářky čtenáři) sledují Petera Attiu, Bryana Johnsona, longevity discourse. Tohle je CZ aplikace toho trendu.
3. **Reverzní content angle.** Většina fitness PR pitche je *„nová metoda"* / *„nový trenér"*. Tady je úhel **„20letý vztah klient/trenér"** — retention story, nikoli akviziční.
4. **Premium concierge tematika** — kontrast „žabky a Instagram" vs „osobní pozornost" sedí na zájem affluent CZ čtenářů.
